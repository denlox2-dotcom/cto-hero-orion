# CTO на страже инфраструктуры

Браузерный платформер: CTO закрывает инциденты, разбирает техдолг, чинит утечки и спасает прод. Четыре комнаты, три сложности, сборка ПАК и общий рейтинг на SQLite.

Игра рассчитана на настольный браузер с клавиатурой. После установки зависимостей она использует локальные ресурсы; LLM, API модели и доступ в интернет для игрового процесса не нужны. Рейтинг обслуживает входящий в проект Node-сервер.

## Быстрый запуск

Нужны **Node.js 24** и npm.

```sh
git clone https://github.com/denlox2-dotcom/cto-hero-orion.git
cd cto-hero-orion
npm ci
npm run build
npm start
```

Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173). Для остановки нажмите Ctrl+C. После изменения исходников повторите сборку.

Обычная ссылка открывает тему К2 НейроТех; [параметр `?theme=aihub`](http://127.0.0.1:4173/?theme=aihub) — тёмную тему AI Hub. Правила общие. Публичная копия использует открытые шрифты IBM Plex Sans и IBM Plex Mono.

Форма регистрации предназначена для **вымышленных тестовых данных**. Укажите имя, фамилию, компанию, телефон или Telegram, отметьте согласие и выберите сложность. Почта необязательна. Тексты о призах в интерфейсе не означают готовность проекта к призовому запуску; ограничения описаны в [документации сервера](docs/DEPLOYMENT.md#данные-и-ограничения).

## Управление

| Клавиши | Действие |
|---|---|
| A / D или ← / → | Движение |
| Пробел | Прыжок; удар по блоку бэклога снизу |
| E, удерживать | Тушить; с ключом рядом с утечкой — чинить |
| Enter | Продолжить на экранах меню и результата |
| Esc | Пауза / продолжение; из финала — в меню |
| Касание предмета | Подобрать кофе, GPU, PRO, монету или ящик с ключом |

Русская раскладка поддерживается через физические коды клавиш. При потере фокуса игра ставится на паузу. Кнопки звука и полного экрана находятся в шапке. Подробные правила — в [GAMEPLAY.md](docs/GAMEPLAY.md).

## Разработка и проверки

```sh
npm run dev              # разработка; адрес напечатает Vite
npm test                 # модульные и серверные тесты
npm run test:e2e         # браузерные сценарии dev-версии
npm run build
npm run test:production  # браузерные сценарии собранной игры
```

Playwright по умолчанию использует установленный Google Chrome. Для поставляемого Playwright Chromium:

```sh
npx playwright install chromium
PLAYWRIGHT_CHROMIUM_CHANNEL=chromium npm run test:e2e
PLAYWRIGHT_CHROMIUM_CHANNEL=chromium npm run test:production
```

Тестовые базы, снимки и трассировки сохраняются в `test-results/`. Команды и устройство проверок — в [DEVELOPMENT.md](docs/DEVELOPMENT.md).

## Структура

| Каталог | Содержимое |
|---|---|
| `src/core/` | Правила, баланс, комнаты, регистрация |
| `src/game/` | Сцена Phaser, клавиатура, звук |
| `src/ui/` | Меню, HUD, паспорт, рейтинг и управление им |
| `src/assets/`, `public/` | Локальные изображения, шрифты, уведомления о лицензиях |
| `server/` | HTTP-сервер, API рейтинга, SQLite, экспорт паспортов |
| `tests/` | Модульные, серверные и браузерные тесты |
| `docs/` | Правила, архитектура, разработка и развёртывание |
